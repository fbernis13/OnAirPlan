# Carnet On Air

Carnet d'entraînement mobile pour le programme de reprise à la salle On Air (4 cycles × 5 séances).

- `index.html` : l'application complète, en un seul fichier (publiée sur GitHub Pages).
- `src/` : sources (programme structuré, vidéos vérifiées, écrans, styles).
- `data/` : catalogue des mouvements (collecte du 09/10/2026). Le programme détaillé reste dans le projet Claude.
- `python3 build.py` régénère `index.html` et `carnet-on-air.html` (version claude.ai).

Les données saisies restent dans le navigateur du téléphone. Exporte régulièrement une sauvegarde JSON depuis l'onglet Sauvegarde.
